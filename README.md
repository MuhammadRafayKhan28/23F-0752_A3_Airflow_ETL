# Currency Exchange ETL Pipeline (Airflow + Astro CLI + MongoDB)

Daily EUR exchange rates are pulled from the **Frankfurter API**, transformed, and loaded into **MongoDB**. **Mongo Express** gives a web UI over the database.

```
extract_exchange_rates  ──XCom "raw_exchange_rates"──▶  transform_exchange_rates
transform_exchange_rates ──XCom "transformed_exchange_rates"──▶  load_into_mongodb
```

## Project structure

```
currency-etl/
├── dags/currency_exchange_etl.py   # the DAG (3 tasks, named XComs)
├── docker-compose.override.yml     # MongoDB + Mongo Express (network, volumes, labels)
├── requirements.txt                # pymongo, requests
├── .env                            # Mongo connection settings
├── Dockerfile                      # generated by `astro dev init`
└── README.md
```

## Run it

```bash
# 1. Create the Astro project (generates Dockerfile, packages.txt, etc.)
mkdir currency-etl && cd currency-etl
astro dev init

# 2. Copy in: dags/currency_exchange_etl.py, docker-compose.override.yml,
#    requirements.txt, .env  (replace the generated requirements.txt)
#    Optionally delete the example DAG in dags/

# 3. Start everything
astro dev start
```

| Service       | URL                    | Login            |
|---------------|------------------------|------------------|
| Airflow UI    | http://localhost:8080  | admin / admin    |
| Mongo Express | http://localhost:8081  | admin / admin123 |
| MongoDB       | localhost:27017        | admin / admin123 |

4. In the Airflow UI, unpause **currency_exchange_etl** and trigger it.
5. Open Mongo Express → `currency_db` → `exchange_rates` to see the documents.

## Docker details

- **Networking:** MongoDB and Mongo Express join Astro's `airflow` bridge network, so the DAG connects with the hostname `mongodb`.
- **Persistent storage:** named volumes `mongodb_data` and `mongodb_config` keep data across restarts.
- **Metadata:** each service and volume carries `com.project.*` labels (check with `docker inspect currency_mongodb`).

## Useful checks

```bash
docker ps                                    # all containers running
docker network ls                            # shows the airflow network
docker volume ls                             # shows mongodb_data / mongodb_config
docker inspect currency_mongodb --format '{{json .Config.Labels}}'
docker exec -it currency_mongodb mongosh -u admin -p admin123 \
  --eval 'db.getSiblingDB("currency_db").exchange_rates.find().pretty()'
```
